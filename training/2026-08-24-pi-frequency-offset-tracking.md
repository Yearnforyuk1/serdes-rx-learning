# PI 跟踪恒定频偏

日期：2026-08-24  
主题：PI-based CDR 的频偏跟踪与相位回卷

## 主问题

一个 16 Gb/s NRZ RX 使用固定频率本地时钟和 PI 完成 CDR 跟踪：

- 本地时钟比发送端快 100 ppm；
- PI 相位范围为 1 UI；
- 128 个等间隔相位码；
- PI code 增大表示采样时钟延迟增大；
- 忽略抖动、量化误差和更新延迟。

要求判断：

1. 不调整 PI 时，累计漂移 1 UI 需要多少 UI？
2. PI code 应增大还是减小？
3. 平均多少 UI 移动 1 LSB？
4. 周期性回卷是否代表失锁，应该观察什么？

## 回答与点评

### 1. 漂移 1 UI 所需时间

最初回答为 100 UI。思路正确，但 ppm 换算少了两个数量级：

```math
100\,\mathrm{ppm}=100\times10^{-6}=10^{-4}
```

所以：

```math
N=\frac{1}{10^{-4}}=10{,}000\ \mathrm{UI}
```

### 2. PI code 方向

回答正确：本地时钟更快，采样沿逐渐超前，因此需要增加采样延迟。按题目给定极性：

```math
\boxed{\text{PI code 持续增大}}
```

### 3. 平均 PI 更新斜率

回答正确：

```math
\frac{10{,}000}{128}=78.125\ \mathrm{UI/LSB}
```

这表示长期平均斜率，并不要求每 78.125 UI 确定跳变一次。

### 4. PI code 回卷

回答正确：频偏存在时，PI code 达到相位范围边界后发生模 1 UI 回卷，并不自动意味着失锁。

判断时应同时观察：

- PI code 的长期平均斜率和方向；
- 回卷前后的等效采样相位是否连续；
- PD 输出统计；
- 回卷瞬间 BER、眼图中心和相位误差是否突变。

## 递进追问

若本地时钟改为比发送端慢 100 ppm：

1. PI code 平均斜率如何变化？
2. 回卷周期是否仍约为 10,000 UI？
3. 若测得约 5,000 UI 的稳定回卷周期，应优先怀疑什么？

## 追问回答与纠正

前两点回答正确：斜率方向反转、理想斜率大小不变，回卷周期仍约为 10,000 UI。

最初把 5,000 UI 周期优先归因于环路带宽捕捉高频 PD 抖动。需要修正：稳定回卷周期减半首先表示等效相位累积速度加倍，应优先排查：

1. 实际频偏是否约为 200 ppm；
2. PI 实际相位覆盖范围是否只有 0.5 UI；
3. code-to-phase 增益或有效码数是否错误；
4. 回卷检测是否把边界往返误判为完整回卷；
5. 最后再检查环路带宽和 PD 高频抖动。

零均值高频抖动通常增加短期 code 波动，不会稳定地把平均回卷周期减半，除非引发周期滑移或非线性误校正。

## 核心总结

```math
\boxed{
T_{\mathrm{wrap}}
=
\frac{\text{PI 相位范围}}{|\Delta f/f|}
}
```

诊断 CDR 时必须区分 PI code 的长期平均相位斜率与短期抖动、边界跳动。
