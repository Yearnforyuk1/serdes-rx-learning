# PI 环路滤波器的即时修正与状态记忆

日期：2026-08-28  
主题：比例项、积分状态与阻尼

## 主问题

数字 PI 环路滤波器为：

```math
I[k]=I[k-1]+K_i e[k]
```

```math
u[k]=I[k]+K_p e[k]
```

给定：

```math
K_p=0.25,\qquad K_i=0.05,\qquad I[-1]=0
```

```math
e[0]=+1,\qquad e[1]=+1,\qquad e[2]=-1
```

要求计算每一步 (I[k])、(u[k])，并区分即时修正和长期记忆。

## 回答与点评

积分状态计算正确：

```math
I[0]=0.05,\qquad I[1]=0.10,\qquad I[2]=0.05
```

前两次总输出正确：

```math
u[0]=0.30,\qquad u[1]=0.35
```

第三次存在符号错误，正确结果为：

```math
u[2]=0.05+0.25(-1)=-0.20
```

概念判断正确：

- (K_pe[k])：只依赖当前 PD 输出，提供即时修正；
- (I[k])：保存历史误差累积，提供长期记忆。

原题曾问“为什么第三次可能仍为正”，但给定参数并不满足该情况；这是题设措辞的问题。只有积分状态大于当前反向比例项时，总输出才会暂时保持原方向。

## 递进追问

保持 (K_i=0.05) 和 PD 序列不变，要使第三次满足：

```math
u[2]>0
```

(K_p) 应满足什么条件？

## 追问回答与纠正

回答正确：

```math
u[2]=0.05-K_p>0
\quad\Rightarrow\quad
\boxed{K_p<0.05}
```

“积分记忆越大，反向修正越困难”的直觉正确。但“因此阻尼越大”需要纠正：在简化的二阶 PI-CDR 中，比例路径才提供主要阻尼。若 (K_p) 太小、积分作用相对过强，系统反而更容易过冲。

## 为什么 (K_p) 对应阻尼？

线性化连续时间模型：

```math
F(s)=K_p+\frac{K_i}{s}
```

相位执行器还包含一次积分 (1/s)，因此闭环特征方程可归一化为：

```math
s^2+K_ps+K_i=0
```

与：

```math
s^2+2\zeta\omega_ns+\omega_n^2=0
```

比较得到：

```math
\omega_n=\sqrt{K_i},\qquad
\zeta=\frac{K_p}{2\sqrt{K_i}}
```

物理上，积分状态会持续推动相位；一旦 PD 反向，比例项立即从 (+K_p) 跳到 (-K_p)，给出即时反向作用，类似刹车。

## 对应的离散模型

采用以下更新顺序：

```math
e[k]=\theta_{in}[k]-\theta_{out}[k]
```

```math
I[k]=I[k-1]+K_ie[k]
```

```math
u[k]=K_pe[k]+I[k]
```

```math
\theta_{out}[k+1]=\theta_{out}[k]+u[k]
```

输入相位固定时，消去积分状态可得：

```math
e[k+1]
=(2-K_p-K_i)e[k]-(1-K_p)e[k-1]
```

特征方程：

```math
\boxed{
z^2-(2-K_p-K_i)z+(1-K_p)=0
}
```

若极点为共轭对，则：

```math
|z_1|=|z_2|=\sqrt{1-K_p}
```

因此在该特定模型和更新顺序下，正的 (K_p) 会把共轭极点拉入单位圆并使振荡衰减。实际数字实现若增加流水线延迟，或 (u[k]) 是绝对 PI code 而非相位增量，方程会发生变化。

## 核心总结

```math
\boxed{
u[k]=\underbrace{I[k]}_{\text{历史趋势}}
+\underbrace{K_pe[k]}_{\text{当前纠偏}}
}
```

PD 反向并不保证总控制量立即反向；方向由历史积分量与当前比例修正的相对大小决定，而 (K_p) 在简化二阶模型中提供主要阻尼。
