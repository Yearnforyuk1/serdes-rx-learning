# PEX 时钟 Buffer 异常：Debug 面试训练

日期：2026-09-04  
模式：Debug 面试  
主题：由现象建立可证伪的排查树  
状态：已结束（用户暂不作答，问题已在实际调试中解决）

## 面试场景

在 TSMC 28 nm 的多通道 SerDes RX 中，有两路版图上看起来对称的差分时钟接收 buffer。每路都由交流耦合、自偏置反相器级联构成。

观察结果：

- 原理图前仿：两路直流工作点和增益接近；
- PEX 只提取 C 或 C+CC：两路仍基本一致；
- 加入寄生 R 后：A 路自偏置节点约 600 mV，B 路约 425 mV；
- 完整级联 AC 增益出现异常，但查看部分中间节点时，各级局部增益似乎又正常；
- 版图肉眼检查未发现明显不同。

题设不能证明一定是寄生电阻、MOS 提取错误、DC 求解错误或 AC 测量定义错误；面试官要看的是如何用证据排除。

## 主问题

请像技术面试现场一样，用“现象 → 假设 → 实验 → 判据”的结构回答：

1. 先用不超过三句话界定问题。哪些是已经确认的事实，哪些还只是怀疑？

2. 给出你优先级最高的三类根因假设，并说明排序依据。至少覆盖：

   - 真实的 RC/连接或版图不对称；
   - DC operating point / 多稳态或收敛问题；
   - AC 激励、差分增益定义或探测参考错误。

3. 设计一个最小实验矩阵，要求尽量少跑仿真，但能区分上述三类假设。每个实验都要说明：

   - 改变什么；
   - 观察什么；
   - 什么结果支持或否定哪条假设。

4. 在重新看 AC 增益之前，你会先比较两路的哪些 DC 数据？请选择最关键的 4–6 项，不要回答“把所有节点都看一遍”。

## 面试表达要求

请先给出一个约 60–90 秒的口头版回答。重点不是猜中某个根因，而是：

- 不把“加 R 后出问题”直接等同于“寄生 R 一定有错”；
- 每个假设都有能将其证伪的实验；
- 先确认工作点和测量定义，再解释 AC 结果。

> 本场只聚焦一个核心能力：面对 PEX 异常时建立有优先级、可证伪的 debug tree。暂不要求给出最终根因。

## 用户决定

用户说明：前仿真没有问题，因此实际排查时优先怀疑后仿真、PEX 或版图相关因素；该工程问题目前已经解决，暂时不希望继续回答本题。
