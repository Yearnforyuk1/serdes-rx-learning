# CDR 为什么需要比例路径和积分路径

日期：2026-08-26  
主题：PD 输出后的数字 PI 环路滤波器

## 模型

Bang-bang PD 输出：

```math
e[k]\in\{-1,0,+1\}
```

数字环路采用：

```math
\omega[k+1]=\omega[k]+K_i e[k]
```

```math
\phi[k+1]=\phi[k]+\omega[k+1]+K_p e[k]
```

其中 (omega[k]) 是每次更新的相位增量，即频率校正状态；(phi[k]) 是展开相位控制量。

## 问题一：为什么频率状态要加到相位上？

疑问是：(K_p e[k]) 直接修正相位容易理解，但为什么 (omega[k]) 也直接加到相位？

关键关系是：

```math
\frac{d\phi(t)}{dt}=2\pi f(t)
```

离散后：

```math
\phi[k+1]=\phi[k]+2\pi f[k]T_u
```

定义：

```math
\omega[k]\equiv2\pi f[k]T_u
```

因此 (omega[k]) 不是绝对频率，而是每个更新周期应增加的相位。非零 (omega) 会在以后每一拍持续推动相位，因而对应频率校正；(K_p e[k]) 只提供当前一次的即时相位修正。

## 问题二：稳定跟踪恒定频偏时会怎样？

回答抓住了 bang-bang CDR 的核心：

- (omega[k]) 不必逐拍完全不变，而会围绕某个非零平均值抖动；
- PD 输出可能在 (+1)、(-1) 之间频繁切换；
- 长期正负输出数量大致相等。

由：

```math
\omega[k+1]-\omega[k]=K_i e[k]
```

累加 (N) 次：

```math
\omega[N]-\omega[0]
=K_i\sum_{k=0}^{N-1}e[k]
```

稳定状态下 (omega) 不能无限增长，因此：

```math
\boxed{\overline e\approx0}
```

有限输出状态带来的来回摆动属于 limit cycle 或 dithering，不等于失锁。

## 问题三：只保留一条路径会怎样？

### (K_i=0)

正确点：没有积分状态更新，不能长期记住频偏；增大 (K_p) 虽能增强单次相位修正能力，却会增大 bang-bang 量化引起的时钟抖动。

需要纠正：只有比例路径并不等于没有阻尼。比例路径根据当前误差立即反向作用，在简化二阶模型中正是主要阻尼来源。外加低通滤波器也不能替代积分器保存频偏，而且额外延迟可能降低相位裕度。

### (K_p=0)

“刹不住车”的判断正确：

1. PD 同号时，积分状态逐渐累积；
2. 相位到达目标附近时，(omega) 已具有较大校正量；
3. 即使 PD 反向，积分状态也需要时间退回；
4. 因而容易产生过冲、振铃或长周期 limit cycle。

## 核心总结

```math
\boxed{
K_p\text{ 负责即时相位修正和主要阻尼，}\qquad
K_i\text{ 负责保存长期频偏信息。}
}
```

还必须区分滤波器本身的积分记忆与整个 CDR 中相位累加器、VCO 或 PI code 状态带来的系统记忆。
