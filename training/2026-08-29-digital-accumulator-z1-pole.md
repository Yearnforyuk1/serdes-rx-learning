# 数字累加器与 z=1 极点

日期：2026-08-29  
主题：CDR 数字环路滤波器——积分路径

## 主问题

CDR 积分路径采用：

```math
I[k]=I[k-1]+K_i e[k]
```

假设初始状态为零，要求：

1. 推导积分路径的传递函数 (H_I(z)=I(z)/E(z))。
2. 找出极点位置。
3. 判断 (e[k]=+1) 时 (I[k]) 是保持不变、线性增长还是指数增长。
4. 解释该极点为什么能够记住频偏，同时带来饱和风险。

## 回答

> (H_I=K_i/(1-z^{-1}))，极点为 (z=1)。最初判断为指数增长，因为下一时刻除了加入 (K_i e[k])，还包含之前的状态。能够记住频偏，是因为路径包含以前的数据；长期积累会带来饱和，而且反向恢复需要时间。

## 点评与关键推理

传递函数和极点判断正确：

```math
H_I(z)=\frac{K_i}{1-z^{-1}},\qquad z_p=1
```

需要修正的是响应类型。若 (e[k]=1)，每拍增加量固定为 (K_i)：

```math
I[k]=I[-1]+(k+1)K_i
```

因此是线性增长，而非指数增长。指数增长要求新增量正比于当前状态，例如 (I[k]=1.1I[k-1])。

当 (e[k]=0) 时：

```math
I[k]=I[k-1]
```

已有状态不会衰减，这就是积分路径的记忆能力。误差长期同号时，状态会持续爬升，有限位宽实现中会发生饱和或 integral windup。

## 递进追问

设 (K_i=0.05)、(I[-1]=0)：

1. PD 只输出一次 (+1)，之后始终为 0，(I[k]) 如何变化？
2. PD 始终输出 (+1)，(I[k]) 如何变化？
3. 为什么 (z=1) 表示状态不衰减，而持续输入才导致线性爬升？

## 追问回答

> 单次 (+1) 后，(I[k]) 保持 0.05 不变。持续 (+1) 时，(I[k]) 以固定斜率线性爬升。(z=1) 表示上一拍状态以系数 1 完整保留，没有新输入时不会衰减；持续输入每次增加固定量，因此不是指数增长。

索引补充：若从 (e[0]=1) 开始，则严格写为：

```math
I[k]=0.05(k+1)
```

## 核心总结

```math
\boxed{z=1\text{ 表示已有状态不衰减；持续同号输入才使累加器线性爬升。}}
```

积分器因此能够保存 CDR 的频率校正量，但数字实现必须考虑有限位宽、饱和与 anti-windup。
