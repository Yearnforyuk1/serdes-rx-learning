# PI 数字环路滤波器的零点

日期：2026-08-31  
主题：从比例/积分差分方程推导零点  
状态：等待主问题回答

## 已知模型

```math
I[k]=I[k-1]+K_i e[k]
```

```math
u[k]=K_p e[k]+I[k]
```

假设初始状态为零，并采用：

```math
\frac{I(z)}{E(z)}=\frac{K_i}{1-z^{-1}}
```

## 主问题

1. 推导从 PD 输出 (E(z)) 到滤波器输出 (U(z)) 的传递函数：

```math
F(z)=\frac{U(z)}{E(z)}
```

并把比例路径与积分路径合并成一个分式。

2. 将结果整理成：

```math
F(z)=A\frac{1-z_0z^{-1}}{1-z^{-1}}
```

找出 (A) 和零点 (z_0)。

3. 取：

```math
K_p=0.25,\qquad K_i=0.05
```

计算零点位置，并判断它是在单位圆内、单位圆上还是单位圆外。

4. 结合此前学过的内容说明：分母中的 (z=1) 极点来自哪个状态？分子中的零点为什么只有在加入比例路径后才出现？

> 本题只关注一个概念：比例路径如何给积分型数字滤波器引入零点。暂不讨论完整 CDR 闭环极点和带宽。
