# PI 数字环路滤波器的零点

日期：2026-08-31  
主题：从比例/积分差分方程推导零点  
状态：已完成

## 已知模型

```math
I[k]=I[k-1]+K_i e[k]
```

```math
u[k]=K_p e[k]+I[k]
```

假设初始状态为零，并采用：

```math
\frac{I(z)}{E(z)}=\frac{K_i}{1-z^{-1}}
```

## 主问题

1. 推导从 PD 输出 (E(z)) 到滤波器输出 (U(z)) 的传递函数：

```math
F(z)=\frac{U(z)}{E(z)}
```

并把比例路径与积分路径合并成一个分式。

2. 将结果整理成：

```math
F(z)=A\frac{1-z_0z^{-1}}{1-z^{-1}}
```

找出 (A) 和零点 (z_0)。

3. 取：

```math
K_p=0.25,\qquad K_i=0.05
```

计算零点位置，并判断它是在单位圆内、单位圆上还是单位圆外。

4. 说明分母中的 (z=1) 极点来自哪个状态，以及为什么加入比例路径后分子才出现有限零点。

## 用户回答

> (F(z)=K_p+K_i/(1-z^{-1}))。  
> (A=K_p+K_i)，(z_0=K_p/(K_p+K_i))。  
> 数值零点为 (5/6)，位于单位圆内。  
> 极点来自积分路径；零点可以算出，但暂时不知道如何解释。

## 点评与关键推理

计算全部正确。合并分式：

```math
F(z)
=K_p+\frac{K_i}{1-z^{-1}}
=\frac{K_p(1-z^{-1})+K_i}{1-z^{-1}}
```

```math
F(z)
=\frac{(K_p+K_i)-K_pz^{-1}}{1-z^{-1}}
=(K_p+K_i)
\frac{1-\frac{K_p}{K_p+K_i}z^{-1}}
{1-z^{-1}}
```

因此：

```math
A=K_p+K_i,\qquad
z_0=\frac{K_p}{K_p+K_i}
```

代入数值：

```math
z_0=\frac{0.25}{0.25+0.05}
=\frac56\approx0.833
```

所以零点位于单位圆内。

### 为什么比例路径会产生零点？

当 (K_p=0) 时：

```math
F(z)=\frac{K_i}{1-z^{-1}}
```

分子只是常数，只有积分路径这一条动态通路，没有有限零点。

加入比例路径后，为了与积分路径使用共同分母，比例项变成：

```math
K_p
=\frac{K_p(1-z^{-1})}{1-z^{-1}}
```

于是分子出现：

```math
K_p(1-z^{-1})+K_i
=(K_p+K_i)-K_pz^{-1}
```

其中 (-K_pz^{-1}) 是延迟一拍的项。零点就是在某种 (z) 模式下，比例直通分量与积分记忆分量恰好抵消的位置。

物理上：

- 积分路径保留历史误差，低频和长期同号误差会不断累积；
- 比例路径直接响应当前误差，不等待累积；
- 两条路径具有不同的时间关系，合并后出现一个可以发生抵消的频率相关分子，因此产生零点。

这个零点会逐渐抵消纯积分器带来的相位滞后，使比例路径能够提供更及时的反向作用；完整的闭环阻尼分析留到后续练习。

## 递进追问

由：

```math
F(z)
=\frac{(K_p+K_i)-K_pz^{-1}}{1-z^{-1}}
```

反推出差分方程，证明：

```math
u[k]-u[k-1]
=K_p\bigl(e[k]-e[k-1]\bigr)+K_i e[k]
```

然后回答：若 PD 从上一拍的 (e[k-1]=+1) 突然翻转为 (e[k]=-1)，这一拍的 (u) 变化量是多少？这如何体现比例路径的“即时刹车”作用？


## 追问回答

> 证明过程略过。若 (e[k-1]=+1)、(e[k]=-1)，则 (u) 的变化量为：
>
> ```math
> -2K_p-K_i
> ```
>
> (K_i) 对应记忆作用，而 (K_p) 前的系数来自即时计算，因此体现及时刹车。

## 最终点评

结果正确：

```math
\begin{aligned}
u[k]-u[k-1]
&=K_p(-1-1)+K_i(-1)\\
&=\boxed{-2K_p-K_i}
\end{aligned}
```

这里需要精确区分“已有记忆”和“本拍新增量”：

- 历史积分记忆已经包含在 (u[k-1])（更直接地说，包含在 (I[k-1])）中；
- 本式里的 (K_i e[k]=-K_i) 是当前这一拍对积分状态新增的反向修正；
- (K_p(e[k]-e[k-1])=-2K_p) 则由 PD 符号翻转立即产生。

因此：

```math
u[k]=u[k-1]-2K_p-K_i
```

若没有比例路径，翻转这一拍只能改变 (-K_i)，积分状态需要逐拍退回；加入比例路径后，立刻额外产生 (-2K_p) 的反向跳变，这就是“即时刹车”。

## 核心总结

```math
\boxed{
\Delta u[k]
=
\underbrace{K_p\Delta e[k]}_{\text{对误差变化的即时响应}}
+
\underbrace{K_i e[k]}_{\text{本拍积分增量}}
}
```

PI 滤波器的零点反映了比例直通路径与积分记忆路径的共同作用：积分器保存长期频偏，比例路径在 PD 翻转时立即改变控制量，从而提供阻尼。
