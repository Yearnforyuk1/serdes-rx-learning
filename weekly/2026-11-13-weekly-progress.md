# SerDes RX 周学习日志｜2026-11-13

- **统计周期：** 2026-11-07 ～ 2026-11-13（中国时间）
- **本周主线：** 18 Gb/s PRBS 接收链路与 Demux 数据正确性、CDR 码型相关锁定、AMS 联合仿真，以及 RX 时钟分频抖动。
- **记录原则：** 区分已讨论的机制、已观察的现象与尚未完成的验证；不把排查假设写成根因结论。

## 1. 本周学习与理解深化

### CDR：码型依赖、误码与锁定状态
- 讨论了 PRBS15 可正常工作、PRBS10/PRBS31 出现问题且 CDR 锁定位置变化的现象。候选机制包括不同码型的游程/频谱特征、ISI 与数据相关抖动、BBPD 判决统计偏置，以及 slicer 后级 TSPC 的动态节点保持与时序裕量；尚未隔离根因。
- 分析了高 BER 下 bang-bang CDR 仍可能维持近乎不变的 PI code：环路锁定/平均相位误差接近零，不等于数据判决 BER 合格；需要同时观察 PD EARLY/LATE、PI code、数据 BER 与眼图。
- 明确了 JTOL、锁定状态与数据正确性不能互相替代。

### Half-rate DFE / Slicers：奇偶路、重定时与 Demux 诊断
- 围绕 18 Gb/s PRBS15 经 half-rate DFE 分成 even/odd，再各自 1:32 Demux 的链路，重点研究单独观测 **even[28]** 时如何验证数据正确性。
- 讨论了 CSV 波形先恢复为 0/1、在眼中心采样、未知 PRBS seed/相位下做序列对齐，以及利用 PRBS 递推/自同步校验识别错误。尚无本周可核实的完整 BER 数值。
- 深入分析高速数据采样、1:4 和 4:32 Demux 是否产生或仅传播 **2 UI 重复/错位**；提出利用自定义码型区分前端采样问题与后级重排问题，但仍需建立单一 even[28] 输出对应的严格理论序列。
- 讨论 1:2 后串行重组的奇偶顺序、PRBS 全反相后的检测，以及示波器/BERT 的 pattern 识别。一次测试中默认奇偶配置正确，并不足以证明所有启动状态和锁定条件下均无需切换。
- 对 TSPC 作为 data slicer 后级采样/重定时单元的码型敏感性，提出晶体管级验证方向：长游程、动态节点泄漏、setup/hold、clock slew、PVT 和寄生。

### RX Clocking / PI
- 研究 **9 GHz 高速时钟约 16 ps TJ** 经 4 分频再 8 分频（总 32 分频）的抖动传递：分频降低输出频率，但不自动消除输入边沿的绝对时间抖动；应区分输出周期抖动、TIE、随机/确定性抖动及分频器自身附加抖动。
- 讨论了 AMS 数字驱动模拟接口出现约 150 ps 边沿时的 connect module / interface element 设置及仿真影响。
- **PI：** 本周主要作为 CDR 锁定状态的观测量出现，无新的 PI 码相位扫描、INL/DNL 或相位插值电路仿真。

### 模拟/数字接口与仿真
- 重点排查 Virtuoso AMS 中 Verilog 正常但 Verilog-A 输出异常或不变化的问题，区分 Spectre 单独仿真与 AMS 下的 view binding、discipline、connect rules、netlist/elaboration 和模型执行。
- 讨论了用简洁 Verilog 替代 1:2 Demux 的前仿方案，利用半速率时钟上升沿/下降沿分别锁存两路数据。
- 讨论 tran 跳过 DC 的风险、DC 求解缓慢，以及长瞬态仿真 checkpoint/restart 的必要性与适用限制。
- **模拟/数字校准：** 本周没有新的 LMS、DCC 或 AFE 校准闭环数据；与之相关的主要是数模接口仿真可靠性。

## 2. 已澄清的问题与现有证据

| 事项 | 当前结论 / 状态 |
|---|---|
| CDR PI code 稳定是否证明低 BER | **否**；锁定指示与数据正确性须独立验证 |
| 分频是否消除高速输入抖动 | **否**；需按具体 jitter 指标和分频边沿关系计算 |
| 单路 Demux 输出能否直接按原始 PRBS 顺序比较 | **不能直接比较**；需先确定抽取步长、lane offset、seed/相位及可能的极性 |
| PRBS 全反相 | 需要结合检测器采用的多项式、极性与同步方式判断，不能仅凭肉眼码型判错 |
| PRBS15 正常、PRBS10/31 异常 | 现象已提出，**根因未证实** |
| AMS 中 Verilog-A 异常 | 已形成分层排查方向，**尚无已验证修复结论** |

## 3. 实验/仿真与证据状态

- **已有测量/文件讨论：** 18 Gb/s PRBS15、half-rate DFE 后 even[28] 的 1:32 Demux 示波器 CSV；围绕波形二值化、眼中心采样和 PRBS 校验方案进行讨论。当前记录不足以证明本周已完成可信 BER 统计。
- **已有现象：** PRBS15 与 PRBS10/31 的 RX/CDR 行为不同；高 BER 情况下 PI code 仍可能稳定；AMS 数字/Verilog-A 联合仿真异常。
- **本周未确认完成：** 2 UI 错误定位、TSPC 晶体管级 PVT 对比、CDR 码型依赖根因、AMS Verilog-A 修复、分频抖动的定量曲线。

## 4. 最重要的待补知识与下一步

1. **优先完成 even[28] 单路 PRBS 验证闭环。** 固定 CSV 采样判决方法，记录阈值/采样相位；从 PRBS15 多项式出发推导 decimation-by-32 后的理论序列，遍历 seed/相位/极性，对比错位、重复与随机误码的统计特征，保留可复现脚本和误码位置。
2. **设计能区分采样级与 Demux 级的自定义码型。** 先推导每种码型在 even[28] 的期望输出，再进行实际测量；重点区分 2 UI 重复来自高速采样还是后级时序/重排。
3. **定位 PRBS 码型相关 CDR 异常。** 在 PRBS15/10/31 下同步记录 BER、PI code、EARLY/LATE、TSPC 内部节点和 slicer 输出；对 TSPC 做长游程及 PVT 晶体管级仿真。
4. **建立时钟分频抖动实验。** 记录 9 GHz 输入与 /4、/32 输出的 TIE/周期抖动，并区分输入继承与分频器新增贡献。
5. **固化 AMS 验证环境。** 对比同一 Verilog-A 模块在 Spectre 与 AMS 的 netlist、connect rule、discipline 和关键波形，避免把接口模型错误误判为 RX 电路错误。

## 5. 求职复盘价值

本周最有价值的能力积累是 **从单路可观测数据反推高速 RX 内部采样与 Demux 错误**，以及 **区分 CDR 相位锁定、数据 BER、TSPC 时序故障和 AMS 仿真接口问题**。后续应将这些讨论转化为“测试配置 → 理论预测 → 观测数据 → 误码定位 → 根因验证”的可复现项目证据。

> **一句话总结：** 本周围绕 PRBS 码型依赖和 half-rate RX Demux 错误建立了较具体的诊断框架，但关键根因和定量 BER 仍待实验闭环；下周优先完成 even[28] 的严格序列验证。
