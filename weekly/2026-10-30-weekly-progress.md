# SerDes RX 周学习日志｜2026-10-30

**统计周期：2026-10-24 ～ 2026-10-30（中国时间）**  
**记录原则：** 区分原理讨论、实际操作和已验证结果；没有数据的内容不写成完成仿真或根因闭环。

## 本周概览

本周重点从上周的 BBPD/JTOL、CMOS PI 和光时钟抖动，转向 **RX AFE 的 ISI/均衡过补、PI 分辨率与速率的关系、RX 附加抖动，以及 PCB—示波器测量链路的电路建模**。另讨论了示波器 BER、MLCC/DTC 及 Virtuoso 工艺模型库切换。没有可核实的新性能曲线或实测结果。

## 1. 核心学习进展

### RX AFE / ISI：欠补偿与过补偿

- 讨论高频补偿不足时的低通拖尾，以及过补偿可能造成的过冲、下冲、反向后游标和振铃。
- **关键澄清：** ISI 应从采样时刻的非主游标响应判断，而不是只看波形是否有拖尾。离散模型可写为 `y[n] = h[0]a[n] + Σ(k≠0)h[k]a[n-k] + η[n]`；欠补偿和过补偿都可能使 `h[k≠0]` 非零，只是符号和分布不同。
- “欠补偿时高频限制眼高、过补偿时低频限制眼高”可作为特定均衡设置下的观察，**不是普适定律**；过补偿也可能放大高频噪声，恶化眼图。
- **状态：** 完成概念分析；尚无同一信道下 CTLE/AFE 扫描、脉冲响应抽样或眼图定量对比。

### PI / CDR：速率提升与相位控制位数

- 讨论为什么 RX 提速后 PI 有时需要增加控制位数。对于覆盖 1 UI 的理想 N 位 PI，`Δt ≈ UI/2^N`；当速率提高、UI 变短时，同位数的绝对时间步长反而减小，而 UI 归一化分辨率不变。
- **关键澄清：** 提速本身并不必然要求增加 PI 位数；是否需要加位应由量化抖动预算、目标相位精度、相位覆盖范围及实际 DNL/INL 决定。
- 本周没有新的 CDR Kp/Ki、BBPD、JTOL 或频偏跟踪实验，也没有新的 PI 全码相位扫描。

### RX Clocking / Slicers：附加抖动的来源

- 梳理 RX 中新增时间抖动的主要机制：噪声经有限边沿斜率转化为 crossing-time jitter（近似 `σt ≈ σv/|dV/dt|`）、ISI 引起的数据相关抖动、供电/地弹噪声、串扰和反射，以及时钟链路、PI/CDR 的相位噪声或量化误差。
- 区分输入端原有抖动与 RX 链路自身引入的抖动；slicer 的噪声、门限和输入 slew 会影响判决时刻与误码表现。
- **状态：** 完成机制讨论；未记录逐级噪声/抖动隔离仿真或 slicer 电路级优化结果。

### 示波器 / PCB 测试：电压测量等效电路

- 明确 PCB 测试口经同轴连接示波器时，若忽略 SMA 和线缆，可先把示波器 **50 Ω 输入建模为测量节点对地的 50 Ω 终端**；示波器读取该端接上的电压，不是无负载地读取源端电压。
- 对比 **1 MΩ 输入 ≈ 1 MΩ ∥ 输入电容**；DC 耦合保留直流，AC 耦合可视为带高通特性的输入路径，可能改变基线和低频内容；有限模拟带宽需另行建模。
- 若信号源内阻为 50 Ω、示波器输入为 50 Ω，则低频端接电压是源开路电压的约一半。是否使用 50 Ω、能否 DC 耦合，要结合输出驱动结构、偏置及仪器规格确认。
- 讨论了高速 PCB 接口（HK-R-FR2 与 SMA-6G-V）的用途和连接方式，但没有记录实际板级测量。
- 澄清示波器的统计/外推 BER 与 BERT 用已知码型逐比特计数的 BER 并不等同；不能把眼图外推结果当成已完成的实测误码计数。

### 供电与仿真工具

- 讨论 DTC/MLCC 及 PSpice MLCC 模型：高频供电仿真需考虑 ESR、ESL、寄生谐振与模型适用频段，不能把 MLCC 当作全频理想电容。
- 在 Virtuoso Maestro 工艺切换后，注意 **Model Libraries 与 Corners 中的模型路径/section 可能仍指向旧 PDK**，应核对并重新生成 netlist；目前没有可核实的修复完成记录。

## 3. 已澄清的问题与验证边界

**已澄清：** ISI 取决于采样时刻残余游标；高频过补可造成反向 ISI/振铃及噪声放大；PI 位数不随数据速率必然增加；50 Ω 示波器输入会加载 DUT；示波器 BER 外推不等于 BERT 直接计数。

**有记录的工作：** 进行了 AFE/ISI、PI 分辨率、RX 抖动与示波器端接的理论分析，讨论了 PSpice MLCC 模型和 Maestro 模型库切换的排查步骤。

**没有证据表明已完成：** CTLE 扫描、PI DNL/INL、CDR JTOL、slicer 噪声仿真、示波器实测 BER、PCB 端接测量或新校准闭环；不填写虚构数值。

## 4. 下周优先级与可交付成果

1. **AFE/ISI（优先）：** 对同一信道设置欠补、近似最佳、过补三种 CTLE/均衡条件；导出脉冲响应的主游标及前/后游标、眼高/眼宽与噪声，验证“反向 ISI”的定量表现。
2. **PI/抖动：** 在两种数据速率下计算相同 PI 位数的绝对时间 LSB 与 UI 归一化 LSB，并结合实际 PI DNL/INL 和 jitter budget 判断是否需要增位。
3. **测试建模：** 在 Spectre 中建立 `DUT 输出等效源 + Rout + 50 Ω 示波器端接`，对照 1 MΩ∥Cin、AC/DC 耦合与带宽限制，记录端接电压和边沿变化。
4. **恢复核心模块：** 完成一项 half-rate DFE feedback timing 或 CDR 闭环量化的定量练习；校准模块没有新数据时继续保留待办。

## 5. 求职复盘价值

本周最值得沉淀的是 **把波形现象还原为可量化的信道游标/噪声问题，以及把“示波器测得的电压”还原为真实负载条件下的电路响应**。这两种思维直接服务于 RX AFE 均衡、抖动预算和芯片测试相关的设计与 Debug。
