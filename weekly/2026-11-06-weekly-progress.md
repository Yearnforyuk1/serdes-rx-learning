# SerDes RX 周学习日志｜2026-11-06

**统计周期：2026-10-31 ～ 2026-11-06**  
**本周主线：多通道 RX 电源完整性、AFE 自适应与监测、ATT 共模反馈、晶体管级版图。**

## 一、本周核心进展

### 1. RX clocking / 70 通道供电完整性
- 围绕约 70 通道 RX、多个供电域、DTC（靠近 die）与 MLCC（PCB 侧）的去耦方案，讨论了只能运行 10 通道晶体管级仿真时的等效建模。
- 明确不能简单把“10 通道端口电流波形复制 7 倍”视作可信的 70 通道供电模型：需区分负载支路电流、去耦电容电流和电源上游电流；还需考虑各通道活动相位相关性、各供电分区的 PDN 阻抗以及 DTC/MLCC 的 ESR/ESL。
- 重点澄清：**增加去耦后局部电压纹波减小，与某一测量支路的瞬时电流波动增大并不矛盾**。电容充放电和谐振电流会改变不同位置的电流；仅凭峰值电流不能判定电源方案优劣。
- 下一步必须明确每个电流探针的位置，并在相同负载激励下分别比较 die 端电压、源端电流、电容电流和频谱；目前没有可核实的 70 通道模型验证结果。

### 2. AFE 自适应 / Slicers：1-bit eye monitor
- 学习了通过扫 slicer 判决阈值、统计输出比例构造电压累积分布（CDF），再通过相邻阈值的有限差分近似 PDF 的方法。
- 关键关系：$F_V(v)=P(V\le v)$，$f_V(v)\approx[F_V(v+\Delta v)-F_V(v-\Delta v)]/(2\Delta v)$。此方法无需多位高速 ADC，但阈值步长、样本数、数据模式和采样相位会影响精度。
- 结合 AFE 自适应专利与 on-die scope 思路展开讨论；尚未完成具体 slicer 阈值扫描或 CDF/PDF 重建仿真。

### 3. ATT / 共模反馈与模拟校准
- 分析了 ATT 输出共模控制的一种非传统共模反馈结构，重点追问其放大器输入/输出关系，以及为什么反馈执行端常接 MOS 栅极，而不是直接钳制源漏节点或电阻节点。
- 建立了区分**共模检测、误差放大、执行器和差模信号通路**的分析框架；但具体电路的环路极性、差模增益影响和稳定性仍需结合完整晶体管连接验证。
- 同时检索/讨论了 ATT 相关专利与论文方向；未确认获得与目标拓扑完全匹配的公开结构。

### 4. 晶体管级与版图基础
- 比较 PMOS/NMOS source follower 的输入共模适用范围、输出摆幅、体效应和驱动特点。
- 围绕 TSMC 28 nm 普通 MOS 与 RF MOS 的版图差异，讨论了独立 guard ring、OD（active/diffusion）、dummy poly 和 NP 等层的用途。具体层定义、DRC 与 PDK 器件结构须以该工艺手册为准。
- 这些内容直接补足 RX AFE 与 clocking 电路的版图知识，但本周未记录具体 layout 修改和 PEX 结果。

## 三、已澄清与尚未闭环

**已澄清的原理：** 去耦后电流峰值增大不必然意味着供电更差；不同电流探针测量的是不同支路。1-bit slicer 的阈值统计可以估计 CDF，差分后可近似 PDF。

**尚未闭环的工程问题：** 70 通道等效电流源是否保留跨通道相关性；不同去耦方案在真实 PDN 中是否产生反谐振；ATT 共模反馈的精确小信号环路；RF MOS 版图差异的具体 PDK 规则。没有证据将这些记为已完成修复或性能验证。

## 四、下周优先级与可交付物

1. **PDN 仿真（首要）：** 在 Spectre 中建立分供电域的 10 通道晶体管负载 + 其余通道行为电流源模型，分别测试同步、错相和随机活动，输出 die 端 $V_{pp}$、RMS 纹波、频谱与电容支路电流。对 DTC/MLCC 扫描 ESR/ESL 与容量，检查反谐振。
2. **Eye monitor 小实验：** 构造已知电压分布，扫 slicer threshold，输出 CDF/PDF 与采样数量误差曲线。
3. **ATT CMFB：** 对实际电路标出共模检测点、执行节点与反馈极性，做共模阶跃和差模 AC 对比。
4. **恢复主线：** 完成一项 half-rate DFE feedback timing 或 CDR 量化闭环的定量练习，避免连续多周缺少核心环路验证。
